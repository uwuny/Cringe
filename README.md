# Анализатор реплеев

Пет-проект: разбираю свои реплеи `.mtreplay`, чтобы после боя можно было
посмотреть, кто куда ехал, кто по кому стрелял и сколько кто нанёс. Плюс сайт
со статистикой команды и справочником по оборудованию.

Делаю для себя и своих одноклановцев, так что где-то код красивый, а где-то
«работает — не трогай».

---

## Что умеет

**Разбор боя.** Из реплея достаются координаты всех машин по времени, выстрелы,
попадания, урон и момент смерти. На выходе — JSON с боем и две HTML-страницы:
карта с движением техники и 3D-визуализатор попаданий.

**Сайт.** Три вкладки: статистика команды по этапам, справочник по картам с
базами и точками возрождения, и оборудование для танков 10 уровня.

---

## Сайт

Открывается как обычная страница, всё работает на статике — ни сервера, ни базы
данных. Ссылки на конкретный экран короткие и ими можно делиться:

```
#tab=stats&stat=hits&season=storm_birth&stage=eternal_storm&date=06.06&avg=left
#tab=maps&map=29_el_hallouf&mode=domination
#tab=equipment&tank=R45_IS-7
```

В адрес пишутся параметры только текущей вкладки, чтобы ссылка не разрасталась.

### Статистика

Таблица боёв по этапам сезона: урон, полученный урон, попадания, ассист,
выживаемость. Есть средние значения и переключатель, с какой стороны их
показывать. Фильтр по датам.

Название клана противника ведёт на Hemero, название карты открывает
интерактивную страницу боя.

### Карты

42 карты, границы и точки берутся прямо из игровых файлов.
Показываются базы, точки возрождения и точки интереса для режимов: Стандартный
бой, Встречный, Натиск, Штурм, Атака/Оборона, Столкновение.

### Оборудование

115 танков 10 уровня, 12 наций, 4 класса (ТТ, СТ, ЛТ, ПТ-САУ). Артиллерию не
добавлял — она мне не нужна.

Для каждого танка два формата: **Рандом** и **АБС**, у каждого своё оборудование.
Плюс показатель эффективности от 1 до 5+.

Устроено так, чтобы не дублировать одно и то же:

- **полевая модернизация** задаётся на роль (например «ЛТ универсальные») —
  картинки и названия одинаковые у всех танков роли и в обоих форматах;
- по танку хранится только то, **какая сторона выбрана** — пять значений вместо
  копии всего блока;
- **оборудование** задаётся по танку, потому что оно у всех разное.

## Что где лежит

```
index.html            сайт: три вкладки
tables.js             статистика и общее состояние ссылки
maps.js               вкладка карт, чтение игровых XML

Equip/
├── equipment_t10.js        собирается генератором
├── equipment_overrides.js  сборки по танкам, собирается редактором
├── equipment_overrides.json     то же, но исходник
├── tank_ratings.txt        состав раздела и оценки, правится руками
├── 10lvl.ndjson            справочник танков 10 уровня
└── Kod_equipment/          модернизация по ролям, 17 файлов

maps/definitions/     игровые XML карт
icons/ flags/ classes/ equipment/ Modernization/ images/   картинки
```

Файлы `equipment_t10.js` и `equipment_overrides.js` генерируются — править их
руками бесполезно, перезапишутся.
